# Estado Cero — Web App Inventario Papelería

## Stack Confirmado
- **Frontend / Server:** SvelteKit + TailwindCSS
- **Backend / DB:** Supabase Cloud (PostgreSQL 15+, Auth, RLS, RPCs)
- **Pruebas Automáticas:** Vitest (`npm run test`)

## Estructura de Rutas Autorizadas
- `supabase/migrations/`
- `src/hooks.server.ts`
- `src/lib/supabase/`
- `src/routes/`
- `src/lib/components/`
- `tests/`
